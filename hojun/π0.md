 ### RT-1, RT-2의 한계
- 로봇의 액션을 이산적인 토큰(discrete tokens)으로 표현
- "그들은 사람과 같은 물리적 세계에 실제로 존재하지 않으며, 물리적 상호 작용에 대한 이해는 전적으로 추상적인 설명에 기반합니다."
    - 고주파수 제어(high-frequency control) 힘듦 = 3Hz
    - 정밀한 연속 동작(dexterous motion) = 이산적 동작

### Transfusion
- 텍스트(이산 데이터)와 이미지(연속 데이터)를 동시에 학습하는 모델
-  텍스트는 다음 토큰 예측(Next Token Prediction) 방식으로, 이미지는 확산 모델(Diffusion Model)을 통해 처리
- Transfusion은 텍스트와 이미지를 동시에 생성하거나, 텍스트 설명을 기반으로 이미지를 편집하는 등 다양한 다중 모달 작업에 활용

### $π_0$
- Transfusion과 달리 flow matching을 사용
    - 기존 Diffusion 방식은 노이즈 추가 → 점진적 제거 과정이 계산비용이 크고 느림
    - 고속 로봇 제어에는 실시간 예측이 필수 → 더 빠르고 안정적인 continuous action 학습이 필요함
- 50 Hz 제어 가능한 Action Chunk(50 스텝) 예측
    - 액션 토큰에서는 보통 6~10개의 행동 변수로 포현
    - 1 청크 = 50개 토큰 = 1초간 행동 (50Hz)
